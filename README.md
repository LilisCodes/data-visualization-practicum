# Data Visualization Practicum

This repository contains my coursework, practical exercises, notes, and data visualization implementations for the **Data Visualization Practicum**.

The practicum covers data visualization using Tableau, ggplot2 in R, Google Data Studio, Power BI, and Python, with practical applications in creating and presenting informative data visualizations.

## Learning Objectives

Through this practicum, I developed skills in:

* Understanding fundamental concepts and principles of data visualization.
* Creating and designing data visualizations using Tableau.
* Creating statistical and informative visualizations using ggplot2 in R.
* Developing interactive data visualizations using Google Data Studio.
* Creating and presenting data visualizations using Power BI.
* Creating data visualizations using Python.
* Selecting appropriate visualization techniques to communicate data effectively.
* Interpreting and presenting insights through data visualizations.
